# Basic commands

## Docker compose

Build:
```shell
docker compose build
```

Run:
```shell
docker compose up
```

Bash into:
```shell
docker compose run --rm -it app bash
```

## Code linting

Flake8:
```shell
flake8 .
```

Black:
```shell
black .
```

Isort:
```shell
isort .
```
